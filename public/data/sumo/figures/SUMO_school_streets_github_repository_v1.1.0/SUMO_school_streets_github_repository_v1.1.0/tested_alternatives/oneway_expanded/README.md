# Tested alternative: bounded one-way diversion

This folder records the v22 feasibility experiment that expanded the OSM network to complete D/E diversion loops.

**Status: tested but not adopted.**

The experiment is retained to document why the publication model keeps D/E as corridor-boundary access experiments. It must not be merged into the primary result tables or used to claim neighbourhood-wide VKT, emissions, congestion or safety effects.

Read `model_scope_decision.md` before inspecting the CSVs. The principal limitations are zero calibrated background traffic on diversion streets, one forced route for all displaced vehicles, and unresolved junction diagnostics in the reduced option.
