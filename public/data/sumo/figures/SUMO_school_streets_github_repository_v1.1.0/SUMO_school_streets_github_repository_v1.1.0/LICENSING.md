# Licensing status

No blanket public license is applied to this working release. Before publication, the repository owner should confirm:

1. the license for original scripts;
2. the license for documentation and processed numerical data;
3. attribution and redistribution conditions for OSM-derived network data;
4. attribution and redistribution conditions for the GTFS-derived timetable;
5. whether the project road-safety report and mobility presentation may be redistributed.

The current package omits the report and presentation and provides checksums and page/slide citations instead. A practical release choice may be a permissive software license for original code and a Creative Commons license for original documentation/data, but that decision belongs to the repository owner and project consortium.
